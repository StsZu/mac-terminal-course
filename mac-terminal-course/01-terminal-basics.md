# Урок 1 — Основи Terminal

## Про тему

**Terminal** — програма, де ви вводите текстові команди замість кліків мишкою. macOS передає команди в **shell** — інтерпретатор, який їх виконує.

На вашому Mac shell — **`zsh`** (Z shell). Перевірка: `echo $SHELL` → `/bin/zsh`.

**Prompt** — рядок перед курсором, наприклад `szubar@MacBook ~ %`. Показує користувача, машину і поточну папку.

- **command** — назва програми: `ls`, `git`, `ping`
- **argument** — значення після команди: `ls Documents`
- **option/flag** — модифікатор, зазвичай з `-`: `ls -la`

**`$PATH`** — список папок, де shell шукає виконувані файли. Розділений двокрапками. Якщо команда «not found» — її немає в PATH або не встановлена.

**Головна мета — не вивчити всі команди, а навчитися швидко знаходити потрібну команду, розуміти її ризик і застосовувати її в реальному сценарії.**

## Команди

### `echo $SHELL`

| | |
|---|---|
| **Що робить** | Виводить шлях до поточного shell |
| **Коли використовувати** | Перевірити, чи працюєте в zsh/bash |
| **Приклад** | `echo $SHELL` |
| **Типовий результат** | `/bin/zsh` |
| **Типові помилки** | Порожній рядок — змінна не задана (рідко на Mac) |
| **Ризик** | низький |

| | |

---

### `history`

| | |
|---|---|
| **Що робить** | Список раніше виконаних команд |
| **Коли використовувати** | Знайти команду, яку вже вводили |
| **Приклад** | `history` або `history \| tail -20` |
| **Типовий результат** | Нумерований список: `  42  git status` |
| **Типові помилки** | Дуже довгий вивід — обмежте `tail` |
| **Ризик** | низький |

**Порада:** `↑` / `↓` — попередня/наступна команда з історії.

---

### `which`

| | |
|---|---|
| **Що робить** | Показує повний шлях до команди з PATH |
| **Коли використовувати** | Дізнатись, яку версію/копію програми запуститься |
| **Приклад** | `which git` |
| **Типовий результат** | `/usr/bin/git` або `/opt/homebrew/bin/git` |
| **Типові помилки** | `git not found` — не встановлено або не в PATH |
| **Ризик** | низький |

---

### `command -v`

| | |
|---|---|
| **Що робить** | Універсальна перевірка наявності команди (POSIX) |
| **Коли використовувати** | У скриптах і коли `which` дає неоднозначний результат |
| **Приклад** | `command -v python3` |
| **Типовий результат** | `/usr/bin/python3` |
| **Типові помилки** | Порожній вивід + exit code 1 — команда відсутня |
| **Ризик** | низький |

---

### `echo $PATH`

| | |
|---|---|
| **Що робить** | Виводить змінну PATH одним рядком |
| **Коли використовувати** | Діагностика «command not found» |
| **Приклад** | `echo $PATH` |
| **Типовий результат** | `/usr/local/bin:/usr/bin:/bin:...` |
| **Типові помилки** | Плутати `$PATH` і `PATH` без `$` |
| **Ризик** | низький |

---

### `echo $PATH | tr ':' '\n'`

| | |
|---|---|
| **Що робить** | Розбиває PATH на окремі рядки для читання |
| **Коли використовувати** | Переглянути всі папки пошуку команд |
| **Приклад** | `echo $PATH \| tr ':' '\n'` |
| **Типовий результат** | Кожна папка на новому рядку |
| **Типові помилки** | Забути лапки навколо `'\n'` |
| **Ризик** | низький |

---

### `man`

| | |
|---|---|
| **Що робить** | Відкриває manual (довідку) по команді |

### `apropos`

| | |
|---|---|
| **Що робить** | Шукає команди за ключовим словом у описах man |

| **Типовий результат** | Список команд з коротким описом |
| **Типові помилки** | Занадто багато результатів — уточніть слово |
| **Ризик** | низький |

## Практичне завдання

1. Відкрийте Terminal. Виконайте `echo $SHELL`, `whoami`, `hostname`, `pwd` — запишіть результати.
2. Перевірте `which git`, `which python3`, `which brew`. Які шляхи?
3. Виведіть PATH у зручному вигляді: `echo $PATH | tr ':' '\n'`.
4. Знайдіть довідку: `man pwd` (вийдіть через `q`). Знайдіть команди: `apropos network`.
