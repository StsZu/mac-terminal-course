# Урок 2 — Файли та папки

## Про тему

Більшість роботи в Terminal — навігація і керування файлами. Шляхи на Mac:

- **абсолютний:** `/Users/szubar/Projects`
- **відносний:** `Projects`, `../Documents`
- **`~`** — домашня папка (`/Users/ваше_ім'я`)
- **`.`** — поточна папка; **`..`** — батьківська

Файли з крапки (`.zshrc`) — приховані; `ls -la` їх показує.

**Головна мета — не вивчити всі команди, а навчитися швидко знаходити потрібну команду, розуміти її ризик і застосовувати її в реальному сценарії.**

### `rm -r`

| | |
|---|---|
| **Що робить** | Рекурсивне видалення **папки** з вмістом |
| **Коли** | Видалити цілу директорію |
| **Приклад** | `rm -r old-project` |
| **Результат** | Папка і все всередині видалені |
| **Помилки** | `Directory not empty` без `-r` |
| **Ризик** | високий |

---

### `rm -rf`

| | |
|---|---|
| **Що робить** | Рекурсивне видалення **без підтверджень** (`-f` = force) |
| **Коли** | Лише коли абсолютно впевнені в шляху |
| **Приклад** | `rm -rf /tmp/test-build` |
| **Результат** | Миттєве видалення без запитань |
| **Помилки** | `rm -rf /` або `rm -rf ~` — катастрофа |
| **Ризик** | **високий** |

#### Різниця `rm` vs `rm -r` vs `rm -rf`

| Команда | Що видаляє | Підтвердження |
|---------|------------|---------------|
| `rm file.txt` | Один файл | Ні (на macOS) |
| `rm -r folder` | Папку з вмістом | Може питати про захищені файли |
| `rm -rf folder` | Папку з вмістом | Ніколи не питає |

**Правило:** перед `rm -rf` завжди `pwd` + `ls` і переконайтесь, що шлях правильний.

## Практичне завдання

1. `cd ~` → `mkdir terminal-practice` → `cd terminal-practice`
2. `touch readme.txt notes.md` → `ls -la`
3. `cp readme.txt readme-backup.txt` → `mv notes.md journal.md`
4. `cat readme.txt` → `head -5 readme.txt`
5. `open .` — перевірте у Finder
6. `rm readme-backup.txt` → `rmdir` не спрацює (папка не порожня) → `rm journal.md readme.txt` → `cd ..` → `rmdir terminal-practice`
