# Урок 3 — Пошук і текст

## Про тему

У реальній роботі постійно шукаєте: файл за ім'ям, рядок у коді, кількість рядків у логу. macOS дає Unix-інструменти (`find`, `grep`) і нативний Spotlight (`mdfind`), плюс буфер обміну (`pbcopy`/`pbpaste`).

**Головна мета — не вивчити всі команди, а навчитися швидко знаходити потрібну команду, розуміти її ризик і застосовувати її в реальному сценарії.**

---

## Команди

### `find`

| | |
|---|---|
| **Що робить** | Шукає файли за ім'ям, типом, датою |
| **Коли** | Знайти файли в проєкті або системі |
| **Приклад** | `find . -name "*.md"` |
| **Результат** | `./README.md` `./docs/guide.md` |
| **Помилки** | `Permission denied` — ігноруйте або обмежте шлях |
| **Ризик** | низький |

Інші приклади:
```bash
find . -name "*.py"
find ~/Downloads -mtime -7    # змінені за 7 днів
```

---

### `grep`

| | |
|---|---|
| **Що робить** | Шукає текст у файлі |
| **Коли** | Знайти слово/патерн у конкретному файлі |
| **Приклад** | `grep "TODO" src/app.js` |
| **Результат** | `src/app.js:42:// TODO: fix bug` |
| **Помилки** | Нічого не знайдено — exit code 1 (не помилка) |
| **Ризик** | низький |

Корисні опції: `-i` (без урахування регістру), `-n` (номери рядків), `-v` (інверсія).

---

### `grep -R`

| | |
|---|---|
| **Що робить** | Рекурсивний пошук у папці |
| **Коли** | «Де в проєкті згадується X?» |
| **Приклад** | `grep -R "TODO" .` |
| **Результат** | Шлях:рядок для кожного збігу |
| **Помилки** | Повільно на великих `node_modules` — виключайте: `grep -R "TODO" . --exclude-dir=node_modules` |
| **Ризик** | низький |

### `sort`

| | |
|---|---|
| **Що робить** | Сортує рядки |
| **Коли** | Впорядкувати список перед аналізом |
| **Приклад** | `sort names.txt` |
| **Результат** | Відсортований вивід |
| **Помилки** | Числове сортування: `sort -n` |
| **Ризик** | низький |

---

### `uniq`

| | |
|---|---|
| **Що робить** | Прибирає сусідні дублікати рядків |
| **Коли** | Після `sort` — унікальні значення |
| **Приклад** | `sort access.log \| uniq` |
| **Результат** | Унікальні рядки (лише підряд) |
| **Помилки** | Без `sort` не прибере всі дублікати |
| **Ризик** | низький |

`uniq -c` — порахувати повторення.

---

| **Результат** | Перша колонка кожного рядка |
| **Помилки** | Невірний роздільник — порожній вивід |
| **Ризик** | низький |

---

### `tr`

| | |
|---|---|
| **Що робить** | Замінює або видаляє символи |
| **Коли** | Перетворення формату тексту |
| **Приклад** | `echo $PATH \| tr ':' '\n'` |
| **Результат** | PATH по одній папці на рядок |
| **Помилки** | `tr: Illegal byte sequence` — кодування |
| **Ризик** | низький |

---

### `xargs`

| | |
|---|---|
| **Що робить** | Перетворює вивід попередньої команди в аргументи наступної |
| **Коли** | Масові операції над списком файлів |
| **Приклад** | `find . -name "*.tmp" \| xargs rm` |
| **Результат** | Видалення всіх `.tmp` |
| **Помилки** | Пробіли в іменах — `find ... -print0 \| xargs -0` |
| **Ризик** | **високий** (з `rm` — перевірте `find` окремо) |

Безпечна перевірка:
```bash
find . -name "*.tmp"   # спочатку подивитись список
find . -name "*.tmp" | xargs rm   # потім видаляти
```

---

### `mdfind`

| | |
|---|---|
| **Що робить** | Пошук через Spotlight (швидкий, індексований) |

| **Приклад** | `mdfind -name "config.json"` |
| **Результат** | Повні шляхи до файлів |
| **Помилки** | Занадто широкий запит — багато результатів |
| **Ризик** | низький |

---

### `pbcopy`

| | |
|---|---|
| **Що робить** | Копіює stdin у буфер обміну macOS |
| **Коли** | Скопіювати вивід команди без виділення мишкою |
| **Приклад** | `cat file.txt \| pbcopy` |
| **Результат** | Текст у буфері; Terminal мовчить |
| **Помилки** | — |
| **Ризик** | низький |

---

### `pbpaste`

| | |
|---|---|
| **Що робить** | Виводить вміст буфера обміну |
| **Коли** | Вставити з буфера в файл або команду |
| **Приклад** | `pbpaste > file.txt` |
| **Результат** | Вміст буфера записано у файл |
| **Помилки** | Перезапише файл без попередження |
| **Ризик** | середній (перезапис файлу) |

## Практичне завдання

1. У папці проєкту: `find . -name "*.md"` — скільки markdown-файлів?
2. `grep -R "TODO" .` — є завдання? Запишіть один результат.
3. Створіть `test.txt` з 5 рядками. `wc -l test.txt`, `sort test.txt`, `cat test.txt | pbcopy`, `pbpaste`
4. `mdfind -name "README"` — знайдіть README на Mac.
5. Пайплайн: `grep -R "function" . --include="*.js" | wc -l`
