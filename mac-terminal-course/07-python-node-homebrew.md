# Урок 7 — Python, Node та Homebrew

## Про тему

На Mac розробка часто йде через три стовпи:

- **Python 3** — скрипти, автоматизація, ML
- **Node.js** — фронтенд, npm-екосистема
- **Homebrew** — менеджер пакетів для macOS CLI-утиліт

Перевіряйте версії перед роботою: `python3 --version`, `node --version`, `brew --version`.

**Головна мета — не вивчити всі команди, а навчитися швидко знаходити потрібну команду, розуміти її ризик і застосовувати її в реальному сценарії.**

---

## Команди

### `python3`

| | |
|---|---|
| **Що робить** | Запуск Python 3 (REPL або скрипт) |
| **Коли** | Виконати `.py` файл, перевірити версію |
| **Приклад** | `python3 --version` / `python3 script.py` |
| **Результат** | `Python 3.12.x` або вивід скрипта |
| **Помилки** | `command not found` — встановіть через brew; `ModuleNotFoundError` — `pip3 install` |
| **Ризик** | низький |

---

### `pip3`

| | |
|---|---|
| **Що робить** | Встановлення Python-пакетів |
| **Коли** | Потрібна бібліотека (requests, pandas) |
| **Приклад** | `pip3 install requests` |
| **Результат** | `Successfully installed requests-x.x.x` |
| **Помилки** | `externally-managed-environment` — використайте venv або `uv` |
| **Ризик** | середній (глобальне встановлення може конфліктувати) |

Краще в проєкті:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip3 install requests
```

---

### `uv`

| | |
|---|---|
| **Що робить** | Швидкий менеджер Python-проєктів і пакетів |
| **Коли** | Нові проєкти; альтернатива pip + venv |
| **Приклад** | `uv --version` / `uv pip install requests` |
| **Результат** | Версія uv або встановлені пакети |
| **Помилки** | Не встановлено — `brew install uv` |
| **Ризик** | низький |

---

### `node`

| | |
|---|---|
| **Що робить** | Запуск Node.js (REPL або JS-файл) |
| **Коли** | Node-проєкти, збірка фронтенду |
| **Приклад** | `node --version` / `node index.js` |
| **Результат** | `v22.x.x` або вивід програми |
| **Помилки** | `command not found` — `brew install node` |
| **Ризик** | низький |

---

### `npm`

| | |
|---|---|
| **Що робить** | Менеджер пакетів Node.js |
| **Коли** | Встановити залежності, запустити скрипти |
| **Приклад** | `npm install` / `npm run dev` |
| **Результат** | `added 150 packages` або вивід dev-сервера |
| **Помилки** | `ENOENT package.json` — не в корені проєкту |
| **Ризик** | середній (postinstall-скрипти в пакетах) |

---

### `npx`

| | |
|---|---|
| **Що робить** | Запуск пакета без глобального встановлення |
| **Коли** | Одноразові CLI-утиліти (create-react-app, eslint) |
| **Приклад** | `npx create-next-app@latest my-app` |
| **Результат** | Інтерактивний майстер або виконання утиліти |
| **Помилки** | Підтвердження встановлення — читайте, що встановлюєте |
| **Ризик** | середній |

---

### `brew`

| | |
|---|---|
| **Що робить** | Homebrew — встановлення CLI на macOS |
| **Коли** | Потрібна утиліта: git, node, wget, jq |
| **Приклад** | `brew --version` |
| **Результат** | `Homebrew 4.x.x` |
| **Помилки** | Не встановлено — див. https://brew.sh |
| **Ризик** | низький |

---

### `brew list`

| | |
|---|---|
| **Що робить** | Список встановлених пакетів |
| **Коли** | «Чи встановлено X?» |
| **Приклад** | `brew list` / `brew list --formula \| grep node` |
| **Результат** | Список формул і casks |
| **Помилки** | — |
| **Ризик** | низький |

---

### `brew search`

| | |
|---|---|
| **Що робить** | Пошук пакета в Homebrew |
| **Коли** | Знайти правильну назву перед install |
| **Приклад** | `brew search python` |
| **Результат** | `python@3.12`, `python-tk@3.12`, ... |
| **Помилки** | — |
| **Ризик** | низький |

---

### `brew install`

| | |
|---|---|
| **Що робить** | Встановлює пакет |
| **Коли** | Потрібна нова утиліта |
| **Приклад** | `brew install jq` |
| **Результат** | `🍺  /opt/homebrew/Cellar/jq/1.7` |
| **Помилки** | `No available formula` — перевірте `brew search` |
| **Ризик** | середній (системні зміни, але контрольовані) |

---

### `brew update`

| | |
|---|---|
| **Що робить** | Оновлює індекс формул Homebrew |
| **Коли** | Перед `upgrade`; раз на тиждень |
| **Приклад** | `brew update` |
| **Результат** | `Updated 2 taps` |
| **Помилки** | Мережеві — перевірте інтернет |
| **Ризик** | низький |

---

### `brew upgrade`

| | |
|---|---|
| **Що робить** | Оновлює встановлені пакети |
| **Коли** | Отримати нові версії утиліт |
| **Приклад** | `brew upgrade` / `brew upgrade node` |
| **Результат** | Список оновлених пакетів |
| **Помилки** | Конфлікти версій — читайте вивід |
| **Ризик** | середній (може зламати залежності проєкту) |

## Сценарії

### Перевірити версію Python і запустити скрипт
```bash
python3 --version
cd ~/Projects/my-script
python3 main.py
```

### Встановити пакет
```bash
pip3 install requests
# або в venv / через uv
```

### Запустити Node-проєкт
```bash
cd ~/Projects/my-app
node --version
npm install
npm run dev
```

### Встановити утиліту через Homebrew
```bash
brew search jq
brew install jq
jq --version
```

---

## Практичне завдання

1. `python3 --version`, `pip3 --version`, `node --version`, `npm --version`, `brew --version`
2. Створіть `hello.py`: `print("Hello")` → `python3 hello.py`
3. `brew search wget` — знайдіть пакет (не обов'язково встановлювати)
4. `brew list | head -20` — що встановлено?
5. Якщо є Node-проєкт: `npm install` і `npm run` (подивіться scripts у `package.json`)
